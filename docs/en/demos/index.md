# Demos

Working demos with code and notes, written so you can copy them into your own project.

## Catalog

| Demo | What it does |
|---|---|
| [DOM-locked Plane](/en/demos/plane) | Runs a shader on a plane that follows the position of a DOM element |
| [Scroll Sync](/en/demos/scroll-sync) | Cards and planes stay perfectly aligned while scrolling |
| [Post Effect](/en/demos/post-effect) | Toggles a Grain post effect on a fullscreen background |

## How to read these demos

Each page is laid out in this order:

1. **Demo** — what is actually running on the page
2. **HTML / TS** — the minimal code that reproduces the demo
3. **Notes** — why it is written this way, and common pitfalls

Combine the pieces of `dom-sync-gl` and you can build the same behavior on your own pages.

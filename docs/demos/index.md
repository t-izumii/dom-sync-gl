# Demos

動くデモ + コード + ポイント解説。コピペで自分のプロジェクトに持っていける形にしてあります。

## カタログ

| デモ | やっていること |
|---|---|
| [DOM-locked Plane](/demos/plane) | DOM 要素の位置に追従する plane に shader を流し込む |
| [Scroll Sync](/demos/scroll-sync) | スクロール中もカードと plane が完全に揃う |
| [Post Effect](/demos/post-effect) | 全画面背景 + Grain ポストエフェクトを ON/OFF |

## このデモの読み方

各ページは次の順で並んでいます。

1. **Demo** — 実際にこの場で動いているもの
2. **HTML / TS** — そのデモを再現する最小コード
3. **ポイント** — なぜこう書くか / よくハマる落とし穴

`dom-sync-gl` の中身を切り貼りすれば、自分のページでも同じ挙動を作れます。

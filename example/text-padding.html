01 — CSS の padding をそのまま引き継ぐ

既定。style の指定なし

padding は getComputedStyle から読み取られ、左右は折り返し幅と描画開始位置に、上下はテキストブロックの配置基準になります。

02 — padding を無視して全面に描く

style: { padding: 0 }（スライダーは効かない）

padding は getComputedStyle から読み取られ、左右は折り返し幅と描画開始位置に、上下はテキストブロックの配置基準になります。

03 — 縦中央（CSS の align-content 由来）

CSS に align-content: center。JS 側の指定なし

padding-bottom はコンテンツ領域の下端を決めます。縦中央では上下の padding が対称に効きます。

04 — 下揃え（JS から上書き）

style: { verticalAlign: 'bottom' }

テキストブロックの下端が padding-bottom の内側に揃います。CSS の align-content より style の指定が優先されます。

05 — 溢れてもクリップしない

verticalAlign: 'center' + コンテンツ領域より多い行数

行数がコンテンツ領域に収まらない場合、位置はクランプされず上下へそのまま溢れます。CSS の overflow: visible と同じ考え方で、板の外まで文字が続きます。収めたい場合は要素の高さか line-height で調整します。

06 — DOM と重ねて検証

hideElementText: false。GL 側だけ赤で描画

白い DOM のテキストと赤い WebGL のテキストが行ごとに重なれば、padding も折り返し位置も一致しています。

domSyncGL is a small Three.js companion that binds shader planes to DOM elements, locks the canvas to native scroll without desync, and lets you compose post-processing chains by extending a single base class.

Peers

01
Composition

Two shaders, one frame, DOM-locked to their host elements.

Each DomPlane reads its hosting element's bounding box every frame and writes itself into a Three.js scene at the corresponding world position. The handoff between layout engine and WebGL is silent — the planes are simply there.

RAYCAST
element-bound planes participate in pointer raycast and receive uIsHovered + uMouseUV automatically.

02
Scroll synchronization

The page and the canvas scroll as one frame.

ScrollSync pins the canvas container to the document with a single rAF-driven transform. There is no parallax desync, no late frame: every plane rides the same scroll snapshot that the page does, every tick.

INVARIANT
rAF reads window.scrollY once per tick and dispatches the value to (a) container transform, (b) per-plane scene position, (c) effect local-UV calc — never independently.

03
Pointer field

Forty-nine planes,
one shared mouse.

Each plane receives global pointer position raycast through the scene. A single hover ripples through the whole field — handled per-plane, without per-element listeners, without per-element state.

COST
one raycast / frame against 49 meshes  ·  ~0.4ms on mid mobile  ·  uniforms updated only on hover transition (no churn).

04
Extending BaseEffect

A post-process,
twenty lines.

Effects are extensions, not the library. Subclass BaseEffect, return your fragment shader, and pass an instance to webgl.addEffect(). The composer wires it into a ping-pong chain automatically — this very page is running one.

RUNNING
PaperEffect: subtle chromatic aberration, warm grade, vignette  ·  1 pass, ~0.2ms.

Build the scene,
ship the page. 
import { WebGLApp, BaseEffect } from "dom-sync-gl";

// canvas, scroll-locked to native scroll
const app = new WebGLApp("#canvas", {
  scrollSync: true,
});

// shader plane bound to a DOM element
app.createPlane(".hero-plane", {
  fragmentShader: myShader,
});

// custom post-process by extension
app.addEffect(new MyGrainEffect());
